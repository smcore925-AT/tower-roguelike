EDITOR TEST — no manual wiring required
1. In Unity Hub, choose Add > Add project from disk and select the folder containing Assets/, Packages/, ProjectSettings/, and AGENTS.md. Use 6000.3.29f1 when opening it.
2. Let package resolution, importing, and shader compilation finish. Open Window > General > Console and confirm there are no red compilation errors.
3. In the Project window open Assets/_Game/Scenes/RunLoopTest.unity.
4. Enter Play Mode. Select the Game tab if needed. The start panel should show Tower Run and Start Run.
5. Click Start Run. The running panel should show Floor 1, Next Floor, and Die (Test).
6. Click Next Floor twice. The label should read Floor 3, increasing once per click.
7. Click Die (Test). The run-over panel should show Run Over, the reached floor 3, and Restart.
8. Click Restart. A new run starts immediately at Floor 1. Repeat steps 6–8 to check that buttons never acquire duplicate listeners.
9. Stop Play Mode. Select Assets/_Game/Data/Core/DefaultRunSettings.asset and set Starting Floor to 5. Enter Play Mode, start a run, advance, die, and restart. Start and restart should use 5; the next floor should be 6. Stop Play Mode and restore Starting Floor to 1.
10. Open Edit > Project Settings > Player > Other Settings > Configuration and verify Active Input Handling is Input System Package (New). Under Graphics, verify Default Render Pipeline references the PC_RPAsset URP asset. Quality levels inherit this default when their Render Pipeline Asset override is None.
11. Stop and re-enter Play Mode; the Start panel should appear again. Resize the Game view and confirm all controls remain visible.
